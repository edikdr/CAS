# Cigarettes After Sex — Fan Sanctuary

A fan-made, unofficial single-page site about the band, built as a cut-paper
collage: headings assembled from scanned paper letters, layered cut-outs
drifting in the background, a lit cigarette trailing smoke and ash.

It holds the full discography (six releases, 48 tracks, plus singles and
covers), profiles of the line-up, timecoded lyric excerpts with a 30-second
preview player, and four quizzes.

Vanilla HTML, CSS and JavaScript — no frameworks, no build step, no CDN. Two
editions: `index.html` with `css/`, `js/` and `assets/` alongside it, and
`cas-fansite-single.html`, the same site folded into one file you can just
open.

Fan-made and unaffiliated with the band or Partisan Records. Lyric lines
appear as short excerpts for identification only.
