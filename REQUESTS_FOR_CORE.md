# REQUESTS FOR CORE

Stage 2 does not edit `core/` or `vendor/`. When you need a core change, add an entry here and work around it meanwhile. An Opus session handles these one at a time.

Template:
```
## <short title>
- What: the smallest change to core you need
- Why: what breaks or is impossible without it
- Workaround in place: what you did meanwhile (file/line)
- Status: open | done (commit)
```
