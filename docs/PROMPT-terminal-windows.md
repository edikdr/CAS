# Промт для новой сессии: HAOTICA Terminal for Windows

Вставить целиком в новую сессию Claude Code на Windows-ноутбуке. ТЗ — в `docs/TZ-terminal-windows.md`.

```
Ты продолжаешь проект HAOTICA в репозитории https://github.com/edikdr/CAS (GitHub: edikdr/CAS).
Сначала прочитай ПОЛНОСТЬЮ, в таком порядке (остальной репозиторий не исследуй широко):
  1) docs/TZ-terminal-windows.md — это твоё ТЗ (что делать, требования, приёмка, этапы M0–M8);
  2) docs/NEXT.md — где остановились, известные проблемы, факты о железе;
  3) docs/HANDOFF.md — устройство проекта и нерушимые правила (раздел 3);
  4) заголовки docs/ARCHITECTURE.md.
Ветка с исходниками: hyprina-os. Работай в НОВОЙ ветке terminal-windows (создай от hyprina-os), коммить и пушь в неё после каждого этапа. PR не создавай, пока не попросят.

Задача: сделать HAOTICA Terminal для Windows (терминал в стиле HAOTICA + локальный ИИ Haotica) по ТЗ. Платформа — только Windows. Модели: 3 локальные для кода (fast Qwen3-1.7B, base Qwen3.8-27B, deep Qwen3-Coder-Next 80B — как в core/haotica/models.py) и 1 локальная модель синтеза речи (выбор — по слепому прослушиванию пользователем, см. W5). Пользователь — русскоговорящий, лимиты ограничены: работай автономно, крупными шагами, отвечай коротко по-русски, не задавай вопросов, когда есть разумное решение по умолчанию; скриншоты — только при отладке.

Среда: Windows 11, Lenovo Legion 7 15ASH11 (Ryzen AI Max+ 392, Radeon 8060S, 64 ГБ общей памяти). Ты запущен на этой Windows-машине (Claude Code) — запускай и проверяй сам: Python 3.12+ x64, git, uv; PySide6 (QtWebEngine), pywinpty (ConPTY), keyring, send2trash, psutil, aiohttp, watchdog; llama.cpp — готовые релизы для Windows. Тесты: Playwright (Chromium) против dev-сервера ядра, тестовый сервер модели tools/fake_llama.py (создай в репозитории по описанию в ТЗ, W8).
Dev-сервер ядра: HAOTICA_DEV_ROOT=<корень репо>, PYTHONPATH=core, python -m haotica.server; агент: python -m haotica.agent; окно: python -m haotica.apps terminal. Токен — в файле token каталога состояния (заголовок X-Haotica-Token или ?token=).

Порядок: M0 → M8 из ТЗ. Начни с M0: ветка, среда, docs/UI-INVENTORY.md (инвентаризация ВСЕХ кнопок/режимов/горячих клавиш текущего терминала с ожидаемым поведением), пакет образцов TTS для слепого прослушивания (по 12 фраз на кандидата; сообщи пользователю, где лежит страница-плеер, и жди его выбор; параллельно продолжай M1). Затем M1 (запуск на Windows, ConPTY, PowerShell-интеграция) и дальше. Не переделывай то, что уже работает; переиспользуй существующий код (список в ТЗ §1).

Нерушимые правила (ТЗ §4): банковский профиль Sparkasse — только изолированный браузерный профиль без доступа Haotica; секреты вычищаются до любой модели, ключи — только в Windows Credential Manager; фильтр опасных команд и карточка подтверждения всегда включены; облачные помощники — только для публичной информации; TLS/подписи не ослаблять; идентификаторы моделей не писать в коммиты/PR/комментарии; стиль — киберретро (OLED-чёрный, янтарь/бирюза/фиолет, CRT: терминал 0,85, аватар +0,25).

Если не хватает лимитов: режь с конца списка (M8→M7…), но никогда не режь W1 (классический терминал) и W3 (безопасное выполнение команд). В конце — короткий отчёт: что работает, что не проверено, команда установки.
```
