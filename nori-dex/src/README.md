# PokéLore — интерактивная вики по лору покемонов (v1.0)

Весь сайт живёт внутри консоли. Архив лёгкий: картинки и данные карточек сайт берёт из интернета (API) в момент просмотра и ничего не хранит. Сервер и ключи не нужны.

**Как открыть.** В корне архива лежит готовая **боевая сборка** (минифицированная): открой `index.html` двойным кликом или залей всю папку на Netlify. Читаемые исходники и сборщик лежат в `src/` (см. «Сборка» ниже).

## Что нового в 1.0

- **Язык интерфейса RU / EN.** Переключатель стоит на экране консоли над кнопкой PLAY (после включения кабеля). Переводится всё: меню, вкладки, лор, викторины, карточки, игра, сканер, подсказки и справка. Выбор запоминается (`localStorage`), переключение перезагружает страницу. Можно и ссылкой: `index.html?lang=en`.
- **Имя тренера.** Поле рядом с переключателем языка; имя показывается в левом верхнем углу главного меню вместо «Тренер» и запоминается.
- **«Ловец»: проще попадать.** Тапни по покемону (или в любую точку поля), и шар полетит точно в него; при смахивании шар сам доворачивает на цель, если смах идёт примерно в её сторону (конус ≈35°, недолёт растягивается до цели, рамка вокруг покемона загорается, когда цель захвачена); хитбокс больше, покемоны медленнее и реже рвутся в сторону, мягче пороги смаха, кольцо бонуса сужается медленнее.
- **Сканер читает намного лучше.** Новый конвейер распознавания (подробности ниже), а главное: всегда показываются несколько совпадений **с превью карточек из основного альбома** и ссылкой на них, а у своих карточек можно править название и описание.
- **Оптимизация без потерь качества** (раздел «Сборка и скорость»).



## Откуда что берётся

| Что | Откуда | Когда |
|---|---|---|
| Покедекс, типы, регионы, поколения, предметы, русские имена | лежат в архиве (`data/`), собраны из PokéAPI | сразу, без интернета |
| **Индекс всех карточек** (20 635 карт, 176 наборов) | лежит в архиве (`data/tcg/index.js`, ≈0,7 МБ) | сразу, без интернета: работают поиск, фильтры, «все карточки» |
| Подробности карточки (атаки, слабость, HP…) | pokemon-tcg-data через jsDelivr / GitHub | при открытии набора или карточки |
| Сканы карточек | `images.pokemontcg.io` → `images.scrydex.com` → TCGdex (API) | при просмотре, по очереди, пока не найдётся |
| Арты покемонов и иконки предметов | PokéAPI/sprites через jsDelivr → GitHub | при просмотре |
| Спрайты викторин (покемоны, предметы, тренеры) | PokéAPI/sprites и **smogon/sprites** (тренеры), jsDelivr → raw.githubusercontent.com | при показе вопроса |
| Новости: новые наборы карточек, свежие игры в базе, заголовки СМИ | pokemon-tcg-data, PokéAPI/api-data, GDELT (всё необязательно) | при открытии «Новостей», кэш 6 часов |

Если скан карточки нет ни в одном источнике, она рисуется сама (с официальным артом покемона). Какой источник сработал для набора, запоминается, и следующие карты этого набора идут сразу в него.

## Что внутри

**Консоль.** Объёмная и матовая, без бликов (`css/console3d.css`): корпус — плита с толщиной, фаской по контуру и утопленным экраном, у джойконов видна боковая стенка и фаска, на верхней грани выступают кнопки питания и громкости. Каждая кнопка — лунка и подвижная шляпка: при нажатии шляпка уходит вниз вместе с тенью, при отпускании пружинит назад, под нажатой кнопкой тихо светится отсвет экрана, слышен сухой механический щелчок. Стики наклоняются в сторону хода и отбрасывают тень, при нажатии на стик он утапливается; плечевые кнопки L / R — дуги с толщиной. Цвет стенок берётся из раскраски, поэтому при смене цвета всё остаётся объёмным.

**Включение.** Сначала видна только консоль, а сверху болтается чёрный кабель USB-C (физика верёвки: качается, тянется за штекером). Чтобы включить, схвати штекер мышью или пальцем и потяни к разъёму на корпусе: рядом с ним штекер «примагничивается» и встаёт ровно, дотянул — входит, загорается индикатор, экран показывает PLAY. Вытащить так же: потянуть штекер от разъёма (или кликнуть по нему), экран гаснет. Для тех, кто не хочет тянуть: клик по разъёму, клавиши P или Enter вставляют кабель сами.

**PLAY.** Джойконы прилетают по дуге сверху (левый) и снизу (правый), выравниваются над рельсами, скользят и защёлкиваются; на экране «Джойконы подключены».

**Раскраска** (7 вариантов, переключатель слева под консолью). При смене старые джойконы отстёгиваются и улетают, новые прилетают с противоположной стороны и защёлкиваются, а корпус «прокатывается» новым цветом.

**Картриджи** (справа от переключателя раскраски, под консолью): четыре настоящих 3D-картриджа, у каждого толщина, фаски, ребристый язычок и этикетка в углублении. Стойка симметрична относительно щели консоли (2 ячейки слева, 2 справа), крайние картриджи чуть повёрнуты к щели.
- Картридж **берёшь рукой и перетаскиваешь вверх, в слот консоли**: он тянется за курсором, наклоняется, у щели выравнивается (подсвечивается слот), по отпусканию въезжает на 80% (снаружи остаётся только стрелка ▼) и защёлкивается. Плашка справа теперь только подсказка и описание.
- Достать: потяни картридж из слота вниз и отпусти. Не дотянул — защёлкнется обратно. Слот занят — другой картридж вернётся на стойку.
- Клавиатура: клавиши 1–4 выбирают картридж, Enter на выбранном вставляет, повторный Enter достаёт.
- Картридж можно вставить и при выключенной консоли: он ждёт, пока ты включишь кабель и нажмёшь PLAY, и тогда запустится его викторина.

**Викторины** (по одной на картридж: «Лор», «Тренеры», «Предметы», по 15 вопросов, 3 сердца). Оформлены как диалоги старых игр (FireRed / Emerald), цветокор в стиле сайта и лёгкие помехи ЭЛТ (зерно, срывы строк, редкий «глюк»):
- вопрос печатается по буквам (пиксельный шрифт Tiny5, с кириллицей), Enter / клик пропускает печать;
- «Кто этот покемон?»: у части вопросов герой кадра чёрный силуэт, пока не ответишь;
- меню с курсором ▶ (↑↓, Enter, клавиши 1–3, мышь), три сердца с анимацией потери, EXP с серией верных ответов;
- герой с напарником у каждого картриджа (Оук и Мью, Ред и Пикачу, Лиф и Иви);
- победа: «Зал Славы» с конфетти и командой героя, ранг по числу ошибок; поражение: экран «Конец игры». Рекорды запоминаются в браузере;
- в меню картриджа можно вместо игры «Читать раздел» (откроются «Легенды и мифы» с нужной вкладкой), а B во время игры спрашивает, прервать ли.
Вопросы и спрайты лежат в `js/quiz-data.js` (поля описаны в начале файла). Спрайты тянутся из PokéAPI/sprites и smogon/sprites при показе вопроса, нет сети — рисуется покебол, а викторина продолжается.

**Четвёртый картридж: «Master Catcher Edition» (аркада «Ловец»).** Этикетка нарисована по фото: пиксельные покеболы на траве и тёмно-синяя плашка с названием (шары рисуются кодом, `js/pixballs.js`). Вставляется так же, как остальные, но запускает не викторину, а игру (`js/catcher.js`, `css/catcher.css`).
- **60 секунд.** На поле появляется покемон (его спрайт берётся из PokéAPI, как в викторине) и носится по нему: бродит, делает рывки, летает волной, ныряет (водные: в этот момент поймать нельзя), а легендарные «мигают» и появляются в другом месте.
- **Подходящий шар.** Восемь шаров, у каждого правило: Покебол (все остальные), Грейт-бол (сумма статов от 400), Ультра-бол (от 500), Фаст-бол (скорость от 100), Хэви-бол (от 200 кг), Нет-бол (водные и насекомые), Даск-бол (тёмные и призрачные), Мастер-бол (легендарные и мифические, ловит всегда, но их только 3 за попытку). Подходит несколько: берётся тот, что правее в лотке. Тип, вес, скорость и сумма статов видны на плашке покемона.
- **EXP:** поймал верным шаром **+200**, поймал другим **+50**, не поймал **−100** (покемон сбегает после пяти бросков или когда на него вышло время). Если время вышло в разгар охоты, а ты уже бросал, покемон убегает (−100); захват, который уже идёт, доигрывается.
- **Бросок:** самое простое — тап по покемону (или в точку поля): шар летит точно в цель. Либо как в Pokémon GO: схвати шар, смахни вверх и отпусти. Скорость смаха задаёт дальность и скорость полёта, направление: куда летит, а покемон бегает, так что бросать нужно с упреждением (небольшая подсказка прицела есть). Круговое движение перед броском даёт **подкрутку**: путь загибается, шанс выше. Вокруг покемона сужается цветное кольцо; чем оно меньше в момент попадания, тем выше шанс («Хорошо / Здорово / Отлично»). Шар попадает, покемон втягивается красным светом, шар падает, качается до трёх раз и щёлкает или раскрывается.
- **Режим AR (X в меню или в игре):** вместо нарисованного поля — камера телефона (задняя), покемон бегает по твоей комнате и при повороте телефона чуть смещается (датчики ориентации). Камера работает по **https** или на телефоне; на `file://` в обычном браузере на компьютере доступ к камере зависит от браузера. Если камеры нет, игра идёт на нарисованном поле.
- Без мыши: стрелки двигают прицел, A бросает, L / R или цифры 1–8 меняют шар, B ставит на паузу.
- **История попыток:** каждая попытка сохраняется (дата, EXP, сколько поймано из скольких, меткость, подробный разбор по каждому покемону: каким шаром, +200 / +50 / −100), последние 40; плюс общий опыт и уровень тренера. Всё хранится в браузере (`pl-catch`).

**Сканер карточек** (кнопка «Скан» в верхней панели главного меню, клавиша Y в альбоме, пункт «Скан» в «Избранном»). Добавляет в альбом твои настоящие карточки:
1. **Откуда взять снимок:** живая камера (карточка ищется на лету, рамка подсвечивается и снимок делается сам, когда карточку держат ровно; кнопка и A снимают вручную) либо **фото из устройства** (галерея / проводник, можно сразу много, можно перетащить картинки на сайт или вставить из буфера). Если живой камеры нет, откроется камера телефона.
2. **Выравнивание и формат:** на снимке находится карточка (контуры, линии Хафа, четырёхугольник с пропорцией 63×88 мм), исправляется перспектива, получается стандартный кадр 630×880 со скруглёнными углами и подтянутой яркостью. Если автоматика ошиблась, нажми Y: углы можно перетащить, а если на фото несколько карточек, тыкни в нужную (`js/scan-img.js`, работает без сети и библиотек).
3. **Распознавание.** Библиотека Tesseract.js и модель (≈3 МБ) один раз скачиваются с jsDelivr (запасной unpkg) и остаются в кэше браузера. Чтение идёт по шагам, от дешёвого к дорогому, после каждого шага сверка с локальным индексом карточек (20 635 карт); как только совпадение уверенное, остальное пропускается:
   - **название** в шапке: адаптивная бинаризация Саувола (переживает блики, градиенты и цветной фон; сначала тёмный текст, затем светлый), срезаются полосы по краю и крапинки;
   - **номер** (020/189, SWSH050) в нижних углах и **HP** справа сверху: они выбирают нужную «печать» среди карточек с одним именем; слэш, прочитанный как «1» или потерянный, и одна неверная цифра тоже прощаются;
   - если название не читается, пробуются другие предобработки (серый, инвертированный, по минимальному каналу, «разреженный» режим), а затем проверяется, не вверх ли ногами карточка;
   - сверка (`js/scan-match.js`) учитывает имя целиком и «вид покемона + приставка» (Charizard + V / EX / VMAX), поэтому криво прочитанная приставка не мешает найти покемона; на синтетическом стенде (блики, шум, размытие, JPEG) нужное имя оказывается среди совпадений в 100% случаев, а точная печать среди 8 лучших в 88–100% (раньше 67% при умеренной порче и 33% при сильной).
4. **Совпадения с превью.** Результат всегда список из нескольких карточек основного альбома: миниатюра, название, набор и номер, HP, редкость, отметки «номер совпал» и «HP», процент. Нажми на миниатюру (или R): превью открывается поверх сканера (L / R листают совпадения, B возвращает к скану); значок ↗ (или L) открывает ту же карточку в основном альбоме (скан ещё не сохранён: просит нажать второй раз). Если ничего не нашлось, сразу открывается поиск по базе с теми же превью, а если карточки в базе нет, она добавится под твоим названием.
5. **Моя коллекция:** выбранная карточка сохраняется в IndexedDB браузера (`js/mine.js`): только отформатированное фото, оригинал не хранится. В альбоме появляется набор «Моя коллекция» (X → «Моя коллекция»); карточка открывается как обычная: если она опознана, показываются данные из базы (атаки, слабость, HP…) и пояснения к частям, но на лице твоё собственное фото. **Название и описание своей карточки можно править**: в окне карточки кнопка ✎ (или Y), пункт «Моё описание» хранит твою заметку (где достал, состояние…). Те же карточки лежат в «Избранном → Моя коллекция».
Фото обрабатывается прямо в браузере и никуда не отправляется. Для живой камеры страница должна быть открыта по https (или локально); без неё работает загрузка файлов. Честно: на реальных фото (альт-арт, сильные блики, мелкая печать) результат зависит от снимка; поэтому сканер не говорит «не узнал» и отпускает, а предлагает варианты с превью, и последнее слово за тобой.

**Вкладки главного меню:** Регионы (10), Покедекс (все 1025 покемонов), Легенды и мифы, Типы (18), Хронология (9 поколений и серии карточной игры), Предметы, Новости (кнопка в системном меню под плитками), Избранное. Вкладки «Персонажи» больше нет: люди переехали в «Легенды и мифы → Досье».

**Покедекс.** В листе покемона теперь 3–4 карточки из разных лет (самая новая, самая старая и две из середины), нажатие открывает карточку, а кнопка ниже ведёт ко всем.

**Легенды и мифы** — четыре вкладки:
- *Мифы мира*: 11 историй (яйцо Аркеуса, птицы Канто, Звонящая башня, Тёмный день Галара, парадоксы Палдеи и др.) с героями мифа, ссылками на покемонов и источником;
- *Досье*: 16 главных героев (Пикачу, Мьюту, Мью, Аркеус, Рэйкваза…) с ролью, текстом, записью Покедекса и карточками, плюс 23 человека с их карточками-«сторонниками»;
- *Теории*: 11 интернет-историй с пометкой «канон / фанатская теория / выдумка / реальный факт»: раскрываешь, читаешь, что известно на самом деле, и голосуешь «Верю / Не верю» (хранится в браузере);
- *Все легенды*: полный список 94 легендарных и мифических покемонов.

**Новости** (за последний год): хронология по месяцам с фильтрами «Игры / Карточки / События / Из сети / Слова авторов». Источники и их статус (подключено / нет ответа) видны вверху:
- карточные наборы за год берутся из данных (ровно по датам), а новые, которых ещё нет в архиве, подтягиваются из pokemon-tcg-data;
- «Свежие игры в базе PokéAPI» читаются из PokéAPI/api-data;
- заголовки мировых СМИ про Pokémon — через открытый GDELT API (A открывает статью в новой вкладке);
- вехи («Pokémon Legends: Z-A», 30-летие серии) отобраны вручную; «слова авторов» даны в пересказе открытых интервью, без выдуманных цитат.
Кнопка X обновляет новости. Без сети остаются архив и вехи.

**Избранное.** Покемона из Покедекса в избранное добавляет покебол: мордочка белеет, краснеет и втягивается в шар, шар закрывается, падает, трижды качается, щёлкает и летит в сердечко, и только после этого покемон попадает в список. Туда же попадают **снимки экрана**: кнопка ◉ на левом джойконе (клавиша C) фотографирует то, что на экране консоли (в избранном их можно открыть, скачать и удалить). Снимок собирается прямо в браузере (экран копируется в SVG и рисуется на canvas, шрифты встроены, картинки из сети вшиваются через fetch), без разрешений и серверов; если какую-то картинку не удалось вшить, на снимке остаётся пустое место.

**Альбом** (кнопка в верхней панели). X открывает «Поиск и наборы»:
- **Поиск по всем карточкам** по имени, русскому или английскому (например, «Чаризард»), с фильтрами по типу, редкости и виду карты (покемоны, тренеры, энергия). Кнопка «Показать карточки» ведёт в альбом с найденным.
- **Любой из 176 наборов** (от Base Set 1999 года до сентября 2026), сгруппированы по сериям.
- **Избранные карточки.**
Из Покедекса можно открыть все карточки конкретного покемона (у Пикачу их 213).

Карточку можно достать из кармашка, повернуть мышью, кликнуть по любой её части и узнать, что она значит. Сердечко (кнопка Y) добавляет в избранное.

## Сборка и скорость

Исходники (`src/`) читаемые, сайт в корне архива собран из них скриптом `scripts/build.mjs`:

```
cd src
npm i                 # terser, csso, html-minifier-terser, acorn (только для сборки)
npm run build         # → src/dist  (готовый сайт; его же можно залить на Netlify)
npm run check:i18n    # проверка перевода: каждая русская строка в коде обёрнута в _(), у каждой есть EN
```

Что сделано для скорости, ничего не теряя в картинке и поведении:
- **JS:** ~30 файлов (RU) или ~55 (EN: словари и английские тексты) склеены и минифицированы в два запроса: данные (`js/data.min.js`) и код нужного языка (`js/app.ru.min.js` / `js/app.en.min.js`); скрипты `defer`, качаются параллельно. Код 637 КБ → 386 КБ (RU).
- **CSS:** 10 файлов → один `css/app.css`, 192 КБ → 152 КБ.
- **Фон:** цветокор фона (насыщенность 1.12, яркость .8, контраст 1.06) запечён в `assets/bg.jpg`, раньше его пересчитывал браузер на каждом кадре на анимированном слое во весь экран (`scripts/bake-bg.py`; оригинал в `assets/src/`). Разница с прежним видом: PSNR > 40 дБ, на глаз не отличить.
- **Кэш:** у бандлов в адресе `?v=<хэш>`, в `_headers` (Netlify) стоит «навсегда» для js/css/шрифтов; `index.html` всегда свежий. Шрифты прогружаются заранее (`preload`), кириллические только в русском режиме; `preconnect` к CDN карточек и данных.
- Тяжёлое грузится по требованию: шрифты для снимков экрана (`js/shot-fonts.js`, 182 КБ) только при первом снимке, Tesseract только при первом скане, картинки карточек по мере просмотра.
- Первая загрузка (локально): 54 файла и 2,81 МБ → 12 файлов и 2,44 МБ (в основном данные: индекс карточек и покедекс, их сжимает сам хостинг).

## Обновить данные

```
node scripts/build-data.mjs
```

Пересобирает лёгкие файлы (`data/`: покедекс, индекс карточек, наборы). Нужен Node.js 18+, ключи не нужны. Это стоит делать, когда выходят новые наборы: подробности карточек и картинки сайт берёт из интернета сам, но поиск находит только то, что есть в индексе.

## Работа без интернета (по желанию)

По умолчанию архив лёгкий, а картинки и данные грузятся из сети. Если нужен офлайн, их можно сложить рядом:

```
node scripts/build-data.mjs --cache-sets     # данные карточек всех наборов (≈10 МБ)
node scripts/build-data.mjs --cache-art      # арты покемонов (≈100 МБ)
node scripts/build-data.mjs --cache-items    # иконки предметов
node scripts/build-data.mjs --all            # всё сразу, плюс список ссылок на сканы
node scripts/fetch-card-images.mjs           # сканы карточек (≈2 ГБ), только после --all
```

Сайт сам заметит локальные копии и будет брать их первыми.

## Источники

- **PokéAPI** (CSV-дамп и sprites на GitHub) — покедекс, типы, регионы, поколения, игры, предметы, официальные арты.
- **PokemonTCG/pokemon-tcg-data** (GitHub) — данные всех карточек и ссылки на сканы.
- **TCGdex** (api.tcgdex.net) — запасной источник сканов карточек.
- **npm-пакет `pokemon`** — русские имена всех 1025 покемонов.
- Описания регионов, поколений и персонажей на русском написаны вручную (`js/lore-ru.js`). Записи Покедекса, тексты атак и описания предметов — на английском, как в источниках.

Шрифты: Nunito и Press Start 2P (SIL OFL), Tiny5 (SIL OFL). Спрайты тренеров: репозиторий smogon/sprites.

Покемоны, арты и карточки принадлежат Nintendo, Game Freak и The Pokémon Company. Это неофициальный некоммерческий фан-проект.
